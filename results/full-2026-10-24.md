# Pilot and full dataset run

Both runs use the same pinned Qwen model, system prompt, greedy decoding and 48-token answer limit. The data split and fitted direction differ. Their scores are on different held-out prompts, so they are not a paired performance comparison.

| Measurement | Earlier pilot | Full dataset run |
| --- | --- | --- |
| Training candidates, harmful / harmless | 56 / 52 | 312 / 312 |
| Accepted training, harmful / harmless | 48 / 48 | 289 / 294 |
| Selected block | 20 | 21 |
| Held-out harmful refusal markers | 24/24 -> 1/24 | 90/104 -> 3/104 |
| Benign first-token KL, nats | 0.124331 | 0.138427 |
| Eight-question exact answers | 6/8 -> 6/8 | 6/8 -> 6/8 |

The full run assigns all 520 harmful prompts and a matched 520-prompt harmless sample. Per source: 312 training candidates, 104 validation and 104 test. The final test IDs exclude all prompts processed in the pilot. Training alone is filtered by observed baseline behavior.

The full run also evaluates all assigned prompts before and after. These results include training and validation and are diagnostics, not held-out scores:

- Harmful: 476/520 -> 4/520 refusal markers.
- Harmless: 33/520 -> 13/520 refusal markers.

No detected refusal does not establish useful, correct or harmful compliance. Eight questions are only a smoke test. Timings were measured on a shared local machine with cached model files; they are not cold-start benchmarks.
